# v0.3 change log and verification record

## Changes
1. `project.godot`: handheld orientation set to `0` (landscape).
2. `scripts/player.gd`: grapple rope constraint now runs on every `_physics_process` tick while attached; radial outward velocity is removed and rope length is enforced.
3. `scripts/virtual_joystick.gd`: new analog virtual joystick with dead zone, axis signal, touch tracking and mouse fallback for editor testing.
4. `scripts/main.gd`: left/right touch buttons removed; joystick drives the movement actions. Action buttons remain independent controls.
5. `scripts/main.gd`: houses and lanterns now use explicit platform-top world positions. House geometry is drawn upward from the platform surface.
6. `scripts/main.gd`: reaching the mission exit opens a results overlay with completion state, rank, time, detection count, defeated enemies, replay and return-to-menu actions. Failure also opens a results overlay.
7. Title screen now suspends player and guard physics until the player starts the mission.

## Checks actually performed
- ZIP archive opened and all entries enumerated successfully.
- `project.godot` inspected; `window/handheld/orientation=0` confirmed.
- Source inspection confirms `_apply_rope(delta)` is called outside the grapple-button edge condition and guarded by `if grappling`.
- Source inspection confirms the two directional touch buttons were replaced by the virtual joystick scene script.
- Source inspection confirms results overlay creation and replay/menu callbacks.
- Source inspection confirms scenery positions now use explicit non-zero platform-top Y coordinates.
- Source files were re-packed into the v0.3 ZIP.
